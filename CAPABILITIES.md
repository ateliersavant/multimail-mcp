# Capabilities

Every claim is graded. **verified** = exercised end-to-end against a real client or API in CI or by hand, with the date. **limited** = works with a stated caveat. **source-only** = implemented and unit-tested, not yet exercised against the real system. **design-only** = specified, no code.

Last updated: 2026-11-03 (Phase 3 hardening: durable audit log, rate limits, adversarial review with nine confirmed findings fixed and kept as regression tests).

## Enforcement pinned by mutation tests

Account allowlist (registry) · account allowlist at the tool layer · principal allowlist at authorisation · principal allowlist on every MCP call · https-only public origin · tenant unknown-key rejection · send-as domain guard · consent-page form-action · egress redirect mode (Workers runtime) · egress redirect refusal · expired store rows · egress host allowlist · id_token signature · HTML stripping · Gmail errors never read as empty · send-as operator list · send-as pending refused · send-as missing in Gmail refused · From re-checked at send time · sent-draft ledger · SENT-label confirmation · ambiguous-send probe · header injection · durable audit sink · audit retention · binding fail-closed · per-client request limit · sending limit · rate-limit window · atomic send claim (Workers runtime) · a released claim never erases a sent record (both stores) · single From header at send · single mailbox in From · Sender matches From · 404 at send is ambiguous · ledger failure reported with the send · no model-written HTML · draft HTML shown · real address always displayed · client metadata host screen (entry and policy) · registration redirect policy · registration limit · Workspace domain at sign-in · egress method · egress exact path · configuration errors carry no values. Each guard is removed in turn by `npm run test:mutation`; the suite must fail every time.

## Does not

Direct send (only approved drafts are sent) · forward · cross-tenant operations · attachment upload or download · deleting mail (only drafts, with `delete_draft`) · HTML bodies · settings or filter changes · non-Google mail · multiple principals.
